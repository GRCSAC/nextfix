# Name check: NextFix (2026-10-09)

Collision search before committing to the name. None of this is legal advice; a trademark
attorney should run a proper clearance before filing.

| Check | Result |
|---|---|
| USPTO (via Trademarkia search) | **0 results** for "nextfix"; "may be available". |
| EUIPO | not checked (JS-only search UI). |
| npm `nextfix` | **free** (404). |
| PyPI `nextfix` | **free** (404). |
| GitHub `GRCSAC/nextfix` | free (our org). The user handle `NextFix` exists; ~20 small unrelated repos use the word (an issue bot, a QuickFIX/J fork, student projects). |
| `nextfix.com` | registered since 2005, renewed to 2027, appears parked/no content. |
| `nextfix.app` | Spanish-language repair-shop management SaaS (orders, inventory, invoices). Different market, same class 42 risk. |
| `nextfix.dev` | Chinese-language "product health scanner": one URL, three minutes, one action; includes a security-vulnerability check. **Closest overlap.** Early stage. |
| `nextfix.tech` | PC repair / IT consulting shop (DNS no longer resolves). |
| `nextfix.io`, `nextfix.ai`, `getnextfix.com` | no DNS; likely available. |

**Assessment:** clearable. The only security-adjacent use (`nextfix.dev`) is a small, new,
non-US website scanner with no sign of a trademark.

**Decision (Paul, 2026-10-09):** NextFix is marketed at **nextfix.grcsac.com** under the
GRCSAC umbrella, like every other GRCSAC product. No standalone domain will be registered.

**Remaining action (Paul):** file an intent-to-use USPTO application for NEXTFIX in classes
9 and 42 before public launch.
